🎵 Spotify Artist Streaming Analytics

📌 Project Overview

Spotify Artist Streaming Analytics is a data analytics mini project that analyzes Spotify music data to identify patterns and trends in artist performance, streaming counts, popularity, genres, release patterns, and audio characteristics.

The project uses Microsoft Excel for data cleaning and preprocessing and Microsoft Power BI for interactive data visualization and dashboard development.

The main objective is to transform raw Spotify data into meaningful insights that can help understand what factors are associated with song popularity and streaming performance.

---

🎯 Objectives

- Analyze Spotify streaming trends.
- Identify the most popular artists and tracks.
- Analyze streaming performance across different genres.
- Study the relationship between popularity and stream count.
- Analyze song release patterns by year, month, quarter, and day.
- Explore audio characteristics such as danceability, energy, tempo, and instrumentalness.
- Compare explicit and non-explicit tracks.
- Analyze streaming performance across different countries.
- Build an interactive Power BI dashboard for data-driven insights.

🧹 Data Cleaning

The raw dataset was cleaned using Microsoft Excel before visualization.

The major preprocessing steps include:

1. Removing duplicate records.
2. Selecting the first 1,000 records for the mini project.
3. Checking and handling missing values.
4. Correcting inappropriate data types.
5. Standardizing text fields such as artist and genre names.
6. Checking numerical columns for invalid values.
7. Converting release-date information into usable date components.
8. Standardizing month information.
9. Removing unnecessary or duplicate columns.
10. Checking calculated and derived fields.
11. Creating a clean dataset for Power BI.
